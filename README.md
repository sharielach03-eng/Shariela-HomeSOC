# Shariela-HomeSOC

This project simulates a Security Operations Center environment using
Windows, Kali Linux, and Wazuh.

Goals:
- Build a virtual SOC lab
- Simulate attacks
- Detect malicious activity
- Investigate logs
- Produce incident reports

Technologies:
- VirtualBox
- Windows 11
- Kali Linux
- Wazuh
- Nmap
- Wireshark
