# Home SOC Project Scope

## Project Objective

The goal of this project is to build a home Security Operations Center (SOC)
environment using virtualization technology and open-source security tools.

## Technologies

- VirtualBox
- Windows 11
- Kali Linux
- Wazuh
- Sysmon
- Nmap
- Wireshark

## Learning Objectives

- Learn virtualization
- Learn networking fundamentals
- Learn SOC operations
- Learn threat detection
- Learn incident response
- Learn log analysis
- Learn basic penetration testing
- Improve documentation skills

## Planned Attack Scenarios

1. Host Discovery Scan
2. Port Scanning
3. Failed Login Attack
4. PowerShell Execution
5. Reverse Shell Simulation

## Deliverables

- Network diagram
- Virtual lab
- Attack simulations
- Detection rules
- Incident reports
- Lessons learned
